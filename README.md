**SOLMAR — Streets of the Sun**, an original open-world crime game for the
browser. Explore Solmar Bay — a sun-soaked coastal city — on foot and by car,
steal cars, outrun the Solmar Bay Police, and run five story missions for
fixer Vera Santos. Traffic, pedestrians, a wanted level with pursuing police,
combat, a HUD with a live minimap, hidden cash stashes, a respray garage, and
saves in localStorage. No build step, no network: every file is static and
the game runs entirely offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move, mouse to aim,
click to shoot, E to steal a car or pick things up, P to pause.
